Screen Inventory

Nine routes reviewed in production. Component requirements mapped per screen.

/user/background-checks Highest Priority

Primary data view. Lists all background check orders with filtering, search, bulk actions, and per-row detail access. The application's home base for most users.

Dominant Organism Data Table (Full Organism) Components needed
Table (sortable, selectable)Search InputFilter DropdownsBulk Action ToolbarColumn ControlsExport MenuPaginationStatus BadgeRow Actions MenuEmpty StateLoading SkeletonError StateCheckbox (row selection)
Notes This screen defines the entire scope of the Data Table organism deliverable. Every element listed must be authored as part of a single, coherent organism — not as independent atoms. The single most complex and highest-impact deliverable in Phase 1.
/user/applicant-profile/:id Detail View

Applicant detail record. Personal information, order history, document status, and available actions for a single applicant.

Dominant Patterns Profile Header · Tab Navigation · Detail Cards Components needed
