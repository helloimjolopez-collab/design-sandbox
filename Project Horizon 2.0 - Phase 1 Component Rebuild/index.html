How to use this site

This site documents three interconnected deliverables produced in April 2026:

  • An honest audit of the Pathway Design System as it exists in Figma today — token pipeline readiness, token architecture issues, and per-component completeness against eight criteria.
  • A full inventory of the PMM Horizon application — nine routes reviewed in production, UI patterns catalogued and mapped to design system components.
  • A prioritised, effort-estimated build list that bridges the two — 20 items in sequenced execution order.

The Side Navigation component — fully authored and verified — is the reference standard throughout. Every other component is assessed against the same eight criteria used to confirm SideNav is complete.

📌 How to read execution order
Items in the Priority Build List are numbered and must be worked in sequence. Each item depends on the items above it being stable. Do not start item 3 before item 2 is done, and do not start any component authoring before item 0 (Token Architecture Clean-Up) is complete.
