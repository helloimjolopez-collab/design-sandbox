Naked, inside a popover

The one place the field is not the trigger: a picker opened from a table row. The panel is the surface, so the field inside it drops its border. It opens at rest, not focused: a search that sits lit up before anyone has touched it reads as broken. This is Borderless=True in the Figma set: a variant axis across all nine states and three sizes. It drops the resting neutral border and keeps every stroke that carries meaning, so Active, Active-Open and the three error states keep theirs.

States

All nine, named as the Figma set names them: Rest, Hover, Active, Active-Open, Selection, Disabled, Error, Error-Hover, Error-Active. There is no Focus state. Active is the state and Active-Open is the same field with its panel down, so the two Focus variants the set used to carry have been folded away. Error-Hover and Error-Active keep an invalid field on the negative stroke ramp instead of handing it back to the neutral one.
